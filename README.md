# 🌍 Global Currency Converter

A simple, user-friendly web application that allows users to convert amounts between different international currencies.

## 🔗 Live Website

**Try the Currency Converter:**
https://mariumf758.github.io/currency-converter/

## ✨ Features

* 💰 Enter any amount for conversion
* 🌎 Select the currency you have
* 💱 Select the currency you want to convert into
* 🔄 Swap currencies with one click
* 🇵🇰 Pakistani Rupee (PKR) included
* 🌍 Supports a wide range of international currencies
* 📱 Responsive design for mobile devices
* 💻 Works on laptops and desktop computers
* ⚡ Quick and simple currency conversion
* 📊 Provides current available exchange-rate values

## 📊 Currency Conversion

Users can select their source currency and target currency and enter the amount they want to convert.

For example:

* 🇵🇰 PKR → 🇺🇸 USD
* 🇵🇰 PKR → 🇬🇧 GBP
* 🇵🇰 PKR → 🇦🇪 AED
* 🇵🇰 PKR → 🇸🇦 SAR
* 🇺🇸 USD → 🇪🇺 EUR
* 🇬🇧 GBP → 🇯🇵 JPY

and many other currency combinations.

## 📱 Responsive Design

The website is designed to work smoothly on:

* 📱 Mobile phones
* 💻 Laptops
* 🖥️ Desktop computers

## 🚀 How to Use

1. Open the website.
2. Enter the amount you want to convert.
3. Select your starting currency.
4. Select the currency you want to convert into.
5. Click **Convert Currency**.
6. The conversion result will be displayed on the screen.
